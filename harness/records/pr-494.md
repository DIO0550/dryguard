## 手戻り

- **Red の worktree を本体と同じ target で走らせ、テストバイナリが消した worktree のパスを指した**

  - `tests/language_cli.rs` / `tests/scan.rs` の一部は、`git apply --cached` で hunk を選んで積んだ
  - 積んだ段ごとに `git stash push --keep-index` で `cargo test` が通ることを確かめた
