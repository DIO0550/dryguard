# PR #132 [Phase 2] 型エイリアスを解決してから型シグネチャを比較する

- マージ日: 2026-08-31
- 関連 Issue: #116
- 差分規模: 28 ファイル / +2457 -42

## ゴールと結果

**ゴール**: 型注釈に書かれた型名を解決してから型シグネチャを比較し、
`(Amount, number) => Amount` と `(number, number) => number` を単一化可能にする。

**結果**: 達成した。ただし**計画の前提が実測で崩れた**。計画は「hover だけで足りる」と
していたが、輸入したエイリアスの使用位置へ hover を送っても `import Amount` としか返らない。
`typeDefinition` で宣言まで辿り、**そのファイルを開かせてから** hover を送る経路が要った。
`textDocument/definition` は import 文へ自己ループし、`textDocument/declaration` は
`-32601` を返す（typescript-language-server 6.0.0 で実測）。

**レビューが 13 巡ついた。** Codex 12 巡・Copilot 1 巡で 33 件。21 件をこの PR で直し、
11 件を #133 へ、1 件を #118 へ積んだ。
