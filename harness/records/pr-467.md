- 達成した:
  - `LanguageOption::Java` を足し、`source_language_of` で `SourceLanguage::Java` へ写した。`accepts_grammar` に `(Java, Java) => true` と、TypeScript / TSX / Rust / Swift を断る腕を足した
  - 完了条件の手での確認の出力を PR 本文に貼った。`scan --lang java` が `.java` だけを走査すること、`--lang ts` と `.java` の `compare` が「一致しません」・exit 2 になること、`check --diff` / `--staged` の 2 つ
  - 「`--lang ts` と `.java` の `compare` が `NOT_CLASSIFIED`」は、#402（PR #460）のマージで先に満たされていた（Issue #390 のコメントのとおり）
- Issue からずれた点（理由は Issue #390 の計画のコメントにある）:
  - Issue の「変更するファイル」は `src/cli.rs` / `src/main.rs` だった。実際には `tests/language_cli.rs` とフィクスチャ 3 つ、README、`docs/dryguard-plan.md` も変えた。main.rs は bin で単体テストを書けないので、#402 の前例に倣って CLI のテストで押さえた
