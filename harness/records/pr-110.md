## この記録を書くこと自体について（判断が要る）

**`README.md` の「マージされた PR 1 本につき 1 ファイル置く」を素直に読むと、この記録が要る。**
一方で、**記録を入れる PR にも記録が要るなら、その PR にもまた記録が要る**。
この回は指摘が 15 件出たので、書かない選択は「同じ形の失敗が 15 件あった」という材料を捨てることになる。

**書く側に倒したうえで、止め方を提案として残す。** 判断は棚卸しの回に委ねる。

- **案 A（今回採ったもの）**: 記録だけの PR にも記録を書く。**指摘 0 件の回で自然に止まる**
  （0 件の記録は 1 段落で済み、その PR がまた 0 件なら次は書かない、と決められる）

  「どの回の指摘か」が 1 段ずれる
- **案 C**: 記録だけの PR は記録を作らない。**この回の 15 件のような材料は残らない**

**Why not（案 C を今回採らない）**: 15 件はすべて同じ形（**確かめずに数を書いた / 引き継いだ**）で、
`pr-107.md` の指摘 21 と同じ根を持つ。**規約の抜けを数える材料としては、むしろ濃い**。

`なし` の通算はこの回で 18 → 34 になる。**語彙を割るときは、コードの欠陥と記録の正確さを
