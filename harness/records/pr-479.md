### 1. `COMMENT_KINDS` の doc が「`<!--` だけが `html_comment`」と書いていた

- 分類: `comment-mismatch`
- 出どころ: 自己修正（実装の検証。サブエージェントの指摘）
- 内容: tree-sitter-typescript 0.23.2 の外部スキャナ（`common/scanner.h` の `scan_closing_comment`）は、
  `<!--` と `-->` のどちらでも `HTML_COMMENT` を返す。表は種別で落とすので振る舞いは正しかったが、
  doc は `<!--` しか書いておらず実体と食い違っていた。「`<!--` / `-->` から行末までが
  `html_comment`」に直し（`97de4ba`）、`-->` を文の間に挟むテストを足した（`65d0ff2`）
- 既存ルール: rules/coding.md「コメントは doc と Why / Why not に絞る」
