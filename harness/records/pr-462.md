  - `docs/dryguard-plan.md` の表の定数名を出し直した
- Issue からずれた点（理由は Issue #441 のコメントにある）:
  - `token_nodes_of` を共有する `syntax::leaf_divergence` の振る舞いも変わるので、そのテストを 2 件足した（指摘 1）
  - Swift の `multiline_comment` と TypeScript の `html_comment` も列に残ることを実行して確かめ、#461 に分けた

- 分類: `plan`
- 出どころ: 自己修正（計画の検証）

- 既存ルール: implementation-flow スキル「3. 計画」の「影響範囲をファイル単位で割る」
- 次にどう防ぐか: 今回は記録のみ

## 手戻り

- 最初に手で走らせた `cargo fmt --check` が落ちた（テスト用ヘルパー `rust_tokens` の折り返し）。`cargo fmt` で直してからコミットしたので、git hooks・CI では落ちていない（`fmt-failure` は CI か git hooks が落とした回の分類なので、指摘として数えない）
