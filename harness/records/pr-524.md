## 手戻り

- 最初に sourcekit-lsp を外部パッケージに対して起動しようとしたところ、実行環境の権限判定（auto mode classifier、理由 `Code from External`）に拒否された。LSP 無しで取れる数だけを集めて、判断待ちで止まった（Issue #408 の 3 つ目のコメント、Discord 通知）。チャットで起動の許可を受けて再開した
- 取得した Swift のツールチェーンは、最初の実行が同じ権限判定に拒否された。`all-keys.asc` で `gpg --verify` し Good signature を確かめてから展開し直すと通った。その時点で tarball は消していたので、取り直した
- 中継スクリプトの集計で、ツールチェーンの初回起動の回だけ `initialize` が 18.20 秒かかっていた。`.build` を消して有効の回を測り直した。2 回目は probe が `.build` を作った後だったので、さらにもう 1 回走らせた
- 計画の検証（手順 4）と実装の検証（手順 6）のサブエージェントは走らせていない。Issue にも PR にもその旨を書いていない
