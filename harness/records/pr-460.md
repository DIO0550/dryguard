## ゴールと結果

Issue #402 のゴールは 2 つ。`--lang swift` を受け付けて `scan` / `check --diff` が Swift だけを走査すること、`compare` が `.swift` の 2 点を比べられ、`--lang` と拡張子が一致しなければ拒否することだった。

- 達成した:
  - `LanguageOption::Swift` を足し、`source_language_of` で `SourceLanguage::Swift` へ写した
  - `report_compare` の `is_rust` による 2 択を、`main.rs` の `accepts_grammar`（`LanguageOption` × `Grammar` の網羅 `match`）に置き換えた。着手前に手で確かめると、`.swift` の 2 点を `--lang ts` で比べても拒否されず、`[REVIEW]`・exit 0 になっていた
  - 完了条件の手での確認（`scan --lang swift` が `.swift` だけを走査する、`--lang ts` と `.swift` の `compare` が exit 2）の出力を PR 本文に貼った
- Issue からずれた点（理由は Issue #402 のコメントにある）:
  - Issue の「変更するファイル」は `src/cli.rs` / `src/main.rs` だった。実際には `tests/language_cli.rs` とフィクスチャ 3 つ、README、`docs/dryguard-plan.md` も変えた。main.rs は bin で単体テストを書けないので、振る舞いは統合テストで押さえた
  - 網羅 `match` にした結果、`--lang ts` / `rust` / `swift` で `.java` を名指しすると exit 2 になる。#390（`--lang java`）の完了条件の半分を先に満たした（#390 にコメント済み）
  - #424（同じ判定を `SourceLanguage::accepts` で引く）の案は採らなかった。`Auto` が Swift / Java を拾わないため（#424 にコメント済み。閉じるかどうかは決めていない）
