## ゴールと結果

Issue #337 のゴールは、`trait Sub: Show` の impl の中の短縮形 `Self::Item`（`Item` は `Show` の関連型）を解決すること。達成した。

- `RustQualifiedProjection::from_shorthand` が、trait impl の中の短縮形を trait 引数の無い投影として読む
- `RustTraitDeclaration` が trait 宣言の supertrait（境界と `where Self:`）と、宣言している関連型の名前を読む
- `supertrait_owner_of` が supertrait の閉包を definition で辿る。読めた宣言のうち、所有 trait 以外に名前を宣言するものが無いときだけ、既存の選択（`selected_impl_projection_of`）で RHS を開く
- 閉包の答えは `RustDeclarationCache::supertrait_owners` でチャンクをまたいで共有する

Issue の「確認すること」への答え:

- supertrait の連鎖: 解決する（`chained`）
- 同名の関連型を持つ supertrait が 2 つある形（E0221）: 選ばない（`both`）
- #310 の `binding_with`: そのまま使えた

所有 trait が `const trait`（`Iterator`）の形は、既存の `associated_owner_position_of` が所有 trait を読めないので、選べないまま残した（`counted`）。

## 実行環境

出どころは Issue #337 の着手時のコメントと「PR 前の記録」、PR 本文の「フックの発火」。

- `echo hook-canary` は、着手時と、3 回の push のうち最初の 2 回の前に走らせ、どれも deny されずに通った（3 回目の `Cargo.lock` の削除の push の前には走らせていない）。セッションを起動した時点のブランチ（`ea9c3ab`）の `.claude/settings.json` の `PreToolUse` には `hook-canary.sh` が配線されていたので、層 3 は不発。`SessionStart` のフックの出力もコンテキストに出なかった。セッションの初期作業ディレクトリはリポジトリの外（`/home/user`）だった
- git hooks（層 2）の pre-commit（fmt）は、どのコミットでも発火した
- rust-analyzer は rustup の proxy から起動できなかった（`Unknown binary 'rust-analyzer'`）。CI と同じ `2026-09-21` のリリースを取得し、sha256 を照合して使った。rust-src は `rustup component add` で入れた。typescript-language-server は `pnpm install --frozen-lockfile` で入れた
- `RUSTDOCFLAGS="-D warnings" cargo doc --no-deps` は、このブランチでも origin/main でも 14 件で落ちる（もとからの broken intra-doc links）。CI はこの検査を走らせていない

## うまくいったこと

- 計画を書く前に、プローブのテストで rust-analyzer の答えを確かめた。hover は短縮形を書かれたまま綴る。definition は曖昧な形でも片方を返す。implementation は supertrait の境界の trait 名を指しても答える。2 つ目が分かったので、definition を信じずに閉包を照合する設計を最初から採れた
- 守りたい検査を 1 つずつ壊して走らせ、assert が落ちるかを確かめた。曖昧さの検査・型引数付きの検査・キャッシュのキーの 3 つ。そのうち 2 つ（型引数付きの検査・キャッシュのキー）で、既存のテストでは落ちないことが分かってテストを直した（指摘 7・9）
- サブエージェントの主張（`const trait` の所有 trait も選べる）を、テストで実測してから採否を決めた
