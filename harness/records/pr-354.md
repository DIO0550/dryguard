## 手戻り

- **判断待ちでの停止**: 計画の検証の後、git の起動の置き場所で止まった（指摘 1）。オーナーの回答は翌日のセッションで受けた。そのあいだに `main` が 3 本先へ進んだ（#346 / #348 / #349。`8280fb9` → `e57e7b1`）ので、作業ブランチを最新の `main` から作り直した
- **下書きの退避**: 止まっている間、差分を読む関数の下書きを作業ツリーの外へ移した（指摘 13）。判断の後に戻して使った
- **実装の検証の後の変更**: 指摘 10・11・12 を直した。採らなかった 1 件は README に書いた
- **計測のやり直し**: 最初の「LSP あり」の計測は、rust-analyzer の component が入っていなかった。そのため握手で落ち、Stage 2 を測れていなかった（stderr で気づいた）。`rustup component add rust-analyzer` で入れて測り直した
- **コミットの分割**: 実装・テスト・文書を別のコミットに分けた（d-market-git のコミットスキル）。そのため、ファイル単位で中間の版を作って積んだ。10 コミットそれぞれで `cargo check --all-targets` が通ることを確かめた
- **副産物**: ignored テストを走らせたときに `tests/fixtures/rust-test-references/Cargo.lock` が生成された。コミットせずに削除した
