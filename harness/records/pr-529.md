## ゴールと結果

Issue #498 のゴールは、Swift の型シグネチャで `typealias` を通る型名を右辺へ展開して比べること。

一部を達成し、残りを分けた。

- 達成: 利用者のソースにある、型引数を取らない `typealias` を右辺へ開く（連鎖を含む）。辿った型名は宣言の場所（`declared type identity`）で比べる。修飾子付きの `public typealias` を見落としていた判定も直した
- 分けた: ジェネリックな `typealias` は #527、`.swiftinterface` の `typealias`（`Codable` / `TimeInterval`）は #528。分けた理由は Issue #498 の計画のコメントにある
- 循環: sourcekit-lsp 6.4.2 は循環した `typealias` の使用位置に hover も definition も返さない。`CyclicAlias` はサーバが答えた場合の防御で、どのテストも通していない
