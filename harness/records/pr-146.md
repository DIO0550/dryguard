## ゴールと結果

Issue #126 のゴールは「語彙表にある語のうち、まだ素の型で持ち回っているものを newtype にする」で、
やることとして `signature text` の 1 語が指定されていた。**達成した。**

`SignatureText` を `lsp::hover`（作る側）に置き、`HoverOutcome::Answered` と
`TypeSignature::from_signature_text` が受ける型を `String` / `&str` から差し替えた。
Issue が見送りに仕分けた 5 語（`reference` / `method` / `specifier` / `report` の text /
`payload`）には手を付けていない。ゴールにこれらは入っていないので、達成の評価は変わらない。

**Issue に無かった変更が 3 つ入った。**

| 変更 | 理由 |
|---|---|
| `SplitSignature::from_signature_text` → `from_spelling` に改名 | 改名しないと同じモジュール内に `from_signature_text` が 2 つ並び、片方が `&SignatureText`、もう片方が `&str` になる |
| 空白しか無い綴りを `Unreadable` にした | newtype の不変条件を作る過程で既存の欠陥が出た（指摘 3） |
| `rules/naming.md` に 1 行追記 | `specifier` / `module path` の節が `ModulePath` に言及している先例に合わせた |
