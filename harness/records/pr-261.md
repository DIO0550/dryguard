## ゴールと結果

Issue #39 のゴール「`--lang ts|rust|auto` で対象の言語に合う grammar と LSP サーバを選び、混在 scan の扱いを決める」は達成した。

- `compare` は `.ts` / `.tsx` / `.rs` から言語を判定して対応するサーバを選び、明示指定と拡張子が食い違えばエラーにする。未対応拡張子のエラーには対象と対応拡張子を示す
- `scan --lang auto` は TS と Rust を同じ走査に含め、Stage 2 を言語ごとのサーバへ問い合わせる。各サーバの失敗は別々に残す
- 異言語ペアは作らない。型・依存・参照の意味情報を同じ基準で比べられないためで、判断と却下した案は [Issue #39 のコメント](https://github.com/DIO0550/dryguard/issues/39#issuecomment-5863845690) に残した
- Rust の型シグネチャ比較は #40 の範囲とし、README の Rust CLI / Stage 2 の説明も今回の実装に合わせた
