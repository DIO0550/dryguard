## ゴールと結果

Swift の参照元のうちテストからの参照が `caller-domain-overlap` を歪める問題（#520）を直す。
Issue が挙げた 2 項目（テストの印の選び方・`.build` の生成物からの参照）を、
**XCTest / Testing を import するファイルの参照をすべて除く**という 1 つの印で閉じた
（`syntax::swift_test_source`・`semantics::caller_domain` の `ReferenceSources::is_test`）。

PR 本文の表（apple/swift-argument-parser 1.6.1・sourcekit-lsp 6.4.2 で main と比べた）では、
参照元に `Tests/` のドメインが入るペアは 445 → 27、`.build` のドメインが入るペアは 9,567 → 0。
残る 27 ペアは XCTest を import しないテスト用ファイルで、#554 に分けた。
却下した案（構文の範囲・`Package.swift` の `testTarget`・除外ディレクトリのパス規則）と理由は
[計画のコメント](https://github.com/DIO0550/dryguard/issues/520#issuecomment-7063842539)にある。

差分規模は、マージコミットの第 1 親 `ca62c1957902223a441c909919d81ab525978bf2` と
マージコミット `4e50c68f6cc2b42866a2e1bcca636b3a07e1226a` の `git diff --shortstat` から取り直した。
