# PR #322 feat: Rust の inherent impl・別 trait の impl の中の <Self as Trait>::Item を、一致する impl から展開する

- 差分規模: 18 ファイル / +1653 -103

## ゴールと結果

Issue #310 のゴールは次の 4 つの関連型選択を解決することだった。

- inherent impl 内の `<Self as Trait>::Item`
- 別トレイトの impl の中の同じ形
- 入れ子の投影（`Self::Item::Nested` / `<<Self as Trait>::Item as Other>::Out`）
- 関連型 RHS の Self

着手時にタスクを分割し、この PR は「Self を直接の対象にした完全修飾形 1 段」の impl 選択に絞った。後続は次の 3 つ。

- #317: 入れ子の投影と RHS の Self
- #318: 型変数が具体的な型に当たる impl・blanket impl・境界の含意
- #321: キャッシュの共有（実装の検証で分けた）

絞った範囲は達成した。

- `textDocument/implementation` で候補 impl を集める
- 型変数の付け替えだけで対象型・trait 引数が一致し、同じ位置の型名が同じ型を指す 1 つを選ぶ
- 選べなかったときは理由付きで測れないにする

既存の `foreign` / `outside` は `UnresolvedAssociatedType` から `Normalized` に変わった。

レビューと CI:

- Copilot のレビュー 1 件（`7b92b68` に対して、`0 open findings`）。レビュースレッドは 0 件
- CI は push した 2 つの head（`7b92b68` / `6d6843c`）とも、Rust・PR body のワークフローがすべて成功した。途中で落ちた実行は無い（`actions_list` のブランチの実行 5 件で確認）

以下の指摘はすべて、PR を出す前の自己修正（計画の検証・実装の検証・実装中）で、採否は Issue #310 のコメントに残してある。
