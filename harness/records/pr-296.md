# PR #296 Rust のテスト内参照を caller domain 集計から除外する

- マージ日: 2026-10-04

## ゴールと結果

Rust のテスト内の参照が本番の caller domain を増やしていた問題を修正した。
LSP の references 応答にパスと UTF-16 の開始位置を保持し、構文木から求めた
テスト範囲と照合してからドメインを数える。`#[test]` 系の関数、単純な `#[cfg(test)]`
の項目、内部 `#![cfg(test)]` のファイル・本体を対象とし、範囲内のヘルパーも除外する。

参照元の解析結果は compare / scan ごとにファイル単位で共有する。
読み込み・構文解析・位置の照合に失敗した場合は部分集計せず、原因を text / JSON に出す。
`--include-tests` による候補チャンクの指定とは独立した処理であり、TypeScript の集計は維持した。
複合 cfg / cfg_attr、別ファイルの mod 宣言からの cfg 伝播、マクロ展開は対象外。
採用・却下した案と分割しなかった理由は
[Issue の計画](https://github.com/DIO0550/dryguard/issues/279#issuecomment-5969787339) に残っている。
