## ゴールと結果

TypeScript のテストが候補を占める程度を実コーパスで測り、`scan` の既定で外す条件を決めて実装した。
`describe` / `it` / `test`（`.only` / `.skip` を含む）の第2引数に直接書いた関数を対象とし、
ファイル全体の除外はヘルパーまで失うため採らなかった。`--include-tests` で復元でき、
`compare` の直接指定と references の収集は変更していない。

呼び出し名によるヒューリスティックであり、同名の業務 API も対象になる。
別名・namespace・`each` 等の認識対象外の形と、テスト内部の通常の関数は残す。
この制限は README と語彙の定義にも記載した。

実測の条件・結果は [Issue の計画](https://github.com/DIO0550/dryguard/issues/278#issuecomment-5968861941) と
[実装・検証結果](https://github.com/DIO0550/dryguard/issues/278#issuecomment-5968921660) に残っている。
対象は RxJS 7.8.1 の Observable / Subject と対応するテストの4ファイルであり、全リポジトリではない。
構造類似度の候補を測ったもので、LSP による分類の比較ではない。

## 手戻り

- 指摘4の期待値を直した。最初の除外テストが実装前に失敗した件は、意図した TDD の Red であり欠陥としては数えない。
- Git の HTTPS 認証情報が無く push が失敗したため、接続済み GitHub プラグインで tree / commit / branch を作成した。[公開時の記録](https://github.com/DIO0550/dryguard/issues/278#issuecomment-5968944707) では、公開 tree と検証済みローカル tree の一致を確認している。
- 実行環境: Codex Work Mode。Claude Code セッション URL は未提供。`echo hook-canary` は通ったが、セッション起動時のフック配線を確認できず、層3の発火は判定できなかった。
- ローカル commit 時の pre-commit は cargo が PATH に無く検査をスキップした。公開前には PATH を設定して `harness/githooks/pre-push` を手動実行し、fmt / clippy / test が成功した（同じ公開時の記録）。
- ローカルの LSP 実サーバテストはサーバ未導入のため未実行だった。CI 側は上表の `cargo test (LSP)` ステップで成功を確認した。
