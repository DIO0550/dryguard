## ゴールと結果

`--format json` の出力をエージェントが安定して読める形に固定する（スキーマを書く・版を出力に載せる・
破壊的変更の扱いを決める・ラベルごとの行動を文書にする。`DO-NOT-EXTRACT` を「直せ」と読ませない）。

達成した。`compare` / `scan` / `check` の最上位に `schema_version: 1` を載せ、
`docs/json-output.schema.json`（draft 2020-12）と `docs/json-output.md` を足した。
スキーマと実装の食い違いは `src/report/json.rs` の 12 件のテストが止める
（版・閉じた語彙・キーの集合。型・範囲・`if`/`then` は当てていない）。

ずれ: スキーマの `type` / `minimum` / `if`/`then` を出力に当てるテストは入っていない
（JSON Schema の検証器の依存追加が要り、`resolve.sh` が要求する nightly が環境に無かった）。
PR 本文で「マージ後に別 Issue にする」と書いたが、この記録の時点ではまだ立てていない。

差分規模はマージコミットの第 1 親 `31dde9f2e9e0f18d16a9fd97be950ddbd2c9b374` と
マージコミットの `git diff --shortstat` から取った。
