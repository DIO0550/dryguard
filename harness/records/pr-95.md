### 2. 分析スクリプトが「測れなかった」を 0 として集計し、閾値の選定を誤らせかけた

- 分類: `missing-signal`
- 出どころ: 自己修正
- 内容: 閾値ごとのラベル内訳を出す awk で、依存先の重なりが**測れなかった**ペア

  「Phase 0 の 16 件に対して 3 倍うるさい」と読み、**より高い閾値（0.65）へ倒しかけた。**

  **`rules/architecture.md`「取れなかったシグナルを既定値で埋めない」が名指しで
  禁じている失敗を、そのルールを持つツールの分析スクリプト側でやった。**
  プロダクト側は `ImportOverlap::Unavailable` を型で分けてあるので、この穴は無い。
- 既存ルール: `rules/architecture.md`「取れなかったシグナルを既定値で埋めない」。
  ただし `rules/` は Rust のプロダクトコードが対象で、**調査用のシェル / awk は射程外**。
  pr-90 の指摘 4（`cd "$(git rev-parse --show-toplevel)"` が無言で続行）と同じ構図で、
  **足場のスクリプトに規約が届いていない。**
