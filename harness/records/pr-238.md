### 2. `probe.sh` の関数名の引き直しが、見つからないときにメッセージを出さずに落ちていた

- 分類: `なし`
- 出どころ: 自己修正
- 内容: `lines="$(grep ... | cut -d: -f1)"` は、`grep` が 0 件だと `set -o pipefail` によって
  代入ごと失敗し、`set -e` で**何も出さずに**止まる。その直後に置いた「1 つだけ見つからない」の
  エラーメッセージまで届かない。push 前に読み直して気づき、`|| true` を付けて件数を数える側で

  確かめた

  持たない。AGENTS.md「強制力の序列」の「フェイルオープンかつサイレント」は検査が走ったかの話で、
  この形はフェイルクローズだが理由が黙る）

## うまくいったこと

- **決定木の写しに自己検査を入れた。** `probe.sh` は `src/classification.rs` の決定木を jq に
  写して判定を出し直す。推定のままの傾きで出し直した判定が全ペアで `scan` の判定と一致しなければ
  止まるようにし、`separate` の枝を `REVIEW` に壊した写しで実際に止まる（jq が exit 5）ことを
  確かめた（`rules/testing.md`「迷ったら、その 1 件だけ実装を壊して走らせる」の考え方を harness に当てた）
- **LSP ありで測った。** `pnpm install --frozen-lockfile` で typescript-language-server を入れ、
  各置き方に `tsconfig.json` を置いた。置かないと呼び出し元ドメインが `project-unrooted` で
  測れず、ディレクトリを見る 2 つのシグナルの片方が黙って落ちる（`tests/corpus/` に当てたとき
  実際にそうなった）。`probe.sh` はサーバが無ければ止まる
- **数値は書く直前に出力から出し直した。** Issue コメント・コミットメッセージ・PR 本文に書いた
  件数（63/4・23/16・14/0、16 件の内訳、ファイル数）は `probe.sh` と `git diff --shortstat` の
  出力から取り、例に挙げた関数名（`markPaid` / `archive` / `findById` / `findBySku`）は該当行を
  `sed -n` で確かめた。差分規模は `harness/ci/pr-body-diff.sh` で突き合わせた
