## ゴールと結果

Issue #400 のゴールは、正規化トークン列が完全に一致する Swift のチャンク 2 つで、束縛した名前の一貫した付け替えと、シグネチャに書かれた型を葉の綴りの違いに数えないこと。

- 達成した:
  - `swift_binders_of` / `swift_condition_binders_of` / `swift_pattern_binders_of` で Swift の束縛を集める
  - `signature_type_nodes_of` の Swift の腕で、引数の型・戻り値・`type_parameters`・`type_constraints` を外す（引数の入れ物はチャンクのノード自身）
  - `simple_identifier` を束縛として扱う葉に足し、`is_outside_name` で外の名前を比べる側に残す。対象はラベル・`.` の直後のメンバー・`:` の直前のラベル
  - Issue が挙げたテスト 4 項目を含め、差分の `fn test_` の追加は 21（`swift_divergence` 20 件・`init_declaration` を直接比べる 1 件）
  - 完了条件の `rules/naming.md` の束縛の段落と、`bound_names_of` の doc を出し直した
- Issue からずれた点（理由は Issue #400 のコメントにある）:
  - Issue 本文の tree-sitter-swift 0.7.3 は、`Cargo.lock` では 0.7.4 だった
  - Issue の表は `parameter` の `name` を束縛に入れるとしていた。ラベルを書かない引数（`func f(x: Int)`）は名前がラベルを兼ねるので、束縛に入れない形にした（指摘 2）
  - `README.md` の Swift の「まだ無いもの」から葉の綴りの違いを外した（Issue の変更するファイルに無かった。指摘 5）
