## ゴールと結果

Issue #327 のゴールは次の 3 つだった。

- 入れ子の投影（`Self::Item::Nested` / `<<Self as Trait>::Item as Other>::Out`）を解決する
- inherent impl・別 trait の impl の中の短縮形 `Self::Item` を解決する
- 関連型 RHS の中の投影を再帰して解決する

着手時に rustc 1.97.0（edition 2024）で確かめると、次の形はコンパイルできなかった。

- `Self::Item::Out`: E0223
- inherent impl の中の短縮形: E0223
- 実装していない trait の impl の中の短縮形: E0220

ゴールの確定で止まって、Issue に案 A / B / C を書いた。オーナーが案 A を選び、ゴールを次の 2 つに絞った。

- 完全修飾形の入れ子 `<<Self as T>::Item as O>::Out`
- 関連型 RHS の中の投影（`Self::X` / `<Self as T>::X` / `<Self::X as O>::Out`）

supertrait の関連型を指す短縮形は #337 に分けた。

絞った 2 つは達成した。

- RHS の中の投影は、RHS を書いた impl を使用側とみなして再帰して開く（`member_of`）
- 入れ子の投影は、内側が閉じた綴り（`closed_spelling`）になったときだけ選ぶ。選ぶのは、型パラメータ・trait 引数・`'static` 以外のライフタイム・関数型を持たない 2 段目の impl のうち、対象型の綴りが等しいもの（`closed_target`）
- 循環と深さは、既存の `CyclicAlias` / `AliasExpansionLimit` で止める
