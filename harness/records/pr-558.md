## ゴールと結果

Issue #528 のゴールは、宣言が `.swiftinterface`（標準ライブラリ・Foundation など）にある Swift の `typealias` を
右辺へ開いて比べること。sourcekit-lsp が生成したインタフェース（`GeneratedInterfaces` の下）の**最上位**の宣言は
開けるようになった。実サーバテスト（sourcekit-lsp 6.4.2）で、`TimeInterval` を通る関数と `Double` の関数が単一化可能、
`Codable` を通る関数と `Decodable & Encodable` の関数が単一化可能になったことを確かめてある。

ゴールからのずれ（偽陰性側に残したもの）: 生成インタフェースの中で字下げされた宣言（`Array.Index` など）・
右辺を綴らない宣言（`AnyObject`。#556）・ツールチェーンの `.swiftinterface` は開かない。`AnyClass` は
`UnopenableAlias` から `NoDefinitionSite` に変わり、その説明文が Rust 向けなのは #557 に分けた。

差分規模は、マージコミット `1da456d4eff5535da12d85028de4bd40caece73e` とその第 1 親の
`git diff --shortstat` から取り直した。
