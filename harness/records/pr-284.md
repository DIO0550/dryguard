## 実行環境

出どころは Issue #270 のコメントと PR 本文。

- `echo hook-canary` は deny されずに通った。起動時のブランチの `.claude/settings.json` には `hook-canary.sh` が

  配線が読まれていない可能性が高い。層 3 は発火していない環境として扱った
- 作業中に `/dev/null` が `/root/.cargo/bin` へのシンボリックリンクに置き換わっていた（原因は特定していない）。
  その間に `lsp::tests::test_client_start_with_a_missing_program_reports_the_server_not_found` が 1 度落ち、
  `git stash` も失敗し、コンテナが再起動した。`/dev/null` を作り直した後の再実行は auto mode の分類器に
  止められたため、pre-push フック（全体の `cargo test`）を通る push もオーナーの許可を待って止まった。
  許可の後、単独でも全体でも通った
- `cargo test -- --ignored` はローカルで走らせていない（typescript-language-server が無く、rust-analyzer は
  握手に答えなかった）。CI の `fmt / clippy / test` は success
