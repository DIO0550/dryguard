# 判例

[AGENTS.md](../../AGENTS.md) の判断基準を dryguard の実例に当てた結果を残す。
計画・実装の検証では関係する分類を参照する。実装中は判断に迷ったときや指摘を受けたときに読む。

| 分類 | 参照する場面 |
| --- | --- |
| [`plan`](process.md#plan) | 計画の入力・変更箇所・外部ツールの挙動を確かめる |
| [`unverified-claim`](process.md#unverified-claim) | 報告に書く数値や主張に根拠を当てる |
| [`claim-staleness`](process.md#claim-staleness) | 実装の修正後に報告を読み直す |
| [`rule-staleness`](process.md#rule-staleness) | 実装の修正後に規約文書の定義や参照を確かめる |

追記するときは [記録テンプレート](../records/TEMPLATE.md) の分類ごとに、何が起きたかと判断の分かれ目を示し、
出典の [記録](../records/README.md) にリンクする。判例の見出しは現在の分類名を使う。記録には当時の分類が残る。
