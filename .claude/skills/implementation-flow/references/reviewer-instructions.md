# レビューの共通指示

レビュー担当は渡された入力とリポジトリを読み、指摘を呼び出し元に返す。確認に必要な材料が欠けていれば、その内容を示す。
コマンドの実行、一時的なファイルの書き換え、指摘の採否と修正は呼び出し元が扱う。

- 指摘ごとに `ファイル:行` または計画の該当箇所、照合した規約・仕様、問題になる条件と結果、修正の方向を書く。
  調査した資料と、追加で実測が必要なことを区別する。
- [記録テンプレート](../../../../harness/records/TEMPLATE.md) から分類を 1 つ選ぶ。該当がなければ `なし` と書く。
- 差分の影響を受ける箇所に絞る。同じ原因の指摘はまとめ、問題が見つからなければ確かめた範囲を返す。
